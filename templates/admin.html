推流方法

方式一：OBS 推流（推荐）

  1. 打开 OBS → 设置 → 推流
  2. 服务器填入：rtmp://{{ request.host.split(':')[0] }}:1935/live
  3. 推流密钥填入上方表格中对应频道的密钥
  4. 点击"开始推流"

方式二：FFmpeg 命令行推流

ffmpeg -re -i video.mp4 -c copy -f flv rtmp://{{ request.host.split(':')[0] }}:1935/live/<推流密钥>

方式三：服务端拉流

在频道设置中填写源 URL（支持 RTMP/RTSP/HLS/SRT），然后点击"拉流"按钮。
